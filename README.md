# Mudeer-aamali (مدير أعمالي)

تطبيق ويب تقدمي (PWA) ذكي لإدارة المهام اليومية وتنظيم الوقت بالذكاء الاصطناعي، مبني باستخدام **Next.js 14** و **Supabase**.

## المميزات الرئيسية
- **تخطيط يومي ذكي بالذكاء الاصطناعي (`generate-plan`)**: يحلل مهامك وأهدافك وينشئ لك جدولاً زمنياً متوازناً لليوم.
- **لوحة تحكم اليوم (`/today`)**: عرض سريع ومركّز للمهام الحالية، الأولويات، ونسبة الإنجاز.
- **نظام إشعارات فورية (`Push Notifications & PWA`)**: تذكيرات ذكية تعمل في الخلفية حتى عند إغلاق المتصفح عبر Service Worker.
- **مصادقة وحماية متكاملة**: نظام تسجيل دخول وحماية مسارات باستخدام Supabase Auth و Next.js Middleware.

## خطوات التشغيل السريع

1. **إعداد قاعدة البيانات (Supabase):**
   - أنشئ مشروعاً جديداً على [Supabase](https://supabase.com).
   - افتح **SQL Editor** وقم بلصق وتشغيل محتوى الملف `supabase/setup.sql`.
   - انشر دوال Edge Functions الموجودة في مجلد `supabase/functions/`.

2. **إعداد متغيرات البيئة:**
   - انسخ ملف `app/.env.example` إلى `app/.env.local` وأضف مفاتيح Supabase ومفتاح OpenAI/Gemini ومفاتيح VAPID للإشعارات.

3. **تشغيل التطبيق محلياً:**
   ```bash
   cd app
   npm install
   npm run dev
   ```
