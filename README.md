# وقتي بذكاء — الإصدار الثاني

تطبيق عربي لإدارة الوقت والمهام، قابل للتثبيت على الهاتف كـ PWA، ويعمل دون مكتبات أو خادم. بيانات المهام تبقى محليًا في المتصفح.

## ما الجديد؟

يجمع الإصدار الثاني المهام غير المؤرخة في «الوارد»، ويعرض المهام حسب اليوم والقادمة خلال سبعة أيام والمتأخرة والمنجزة. يتيح الالتقاط السريع تفسير كلمات عربية محدودة للتاريخ والوقت، ويعرض معاينة قبل الحفظ. يستطيع المستخدم مراجعة مهام اليوم وتأجيل أي مهمة إلى الغد مع تراجع، واختيار مهمة مناسبة الآن حسب قواعد واضحة للأولوية والتأخر والمدة. تظهر أيضًا تقديرات عبء اليوم، وتكرار يومي أو أسبوعي أو شهري يُنشئ الموعد التالي عند إكمال المهمة، ومؤقت تركيز قابل لتغيير المدة. أضيف التصدير والاستيراد والدمج المحلي لملف JSON.
