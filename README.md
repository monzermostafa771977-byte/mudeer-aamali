# وقتي بذكاء — الإصدار الثالث

مدير أعمال شخصي عربي يعمل محليًا في المتصفح ويمكن نشره مجانًا على GitHub Pages كـ PWA. لا يحتاج إلى مكتبات أو خادم.

## ما الذي أضيف بالاستفادة من النموذج المرفق؟

- تقويم شهري محلي يعرض عدد المهام في كل يوم؛ الضغط على يوم يفتح مهامه في مساحة العمل.
- دفتر أفكار مستقل عن قائمة المهام، مع إمكانية تحويل الفكرة إلى مهمة في الوارد أو حذفها.
- حفظ اسم اختياري يظهر في التحية، وتبديل بين المظهر الفاتح والداكن.

جاءت هذه الأفكار من الأقسام المرئية في صفحة HTML المرفقة. لكن الصفحة المرفقة كانت تشير إلى ملفات تنفيذ وتنسيق غير موجودة معها (`app.js` و`styles.css` و`manifest.webmanifest` و`assets/icon.svg`)، لذلك لم يكن ممكنًا التحقق من طريقة عملها أو تخزينها؛ لم تُنقل أي شيفرة أو بيانات منها. كما أن مساحة المشروعات في النموذج كانت معلّمة بأنها قيد التجهيز، لذلك لم أضف واجهة مشروعات شكلية. تفاصيل المقارنة في `research/attached-app-review.md`.

## الميزات الأساسية المتاحة

يشمل الإصدار أيضًا الوارد للمهام غير المؤرخة، وعروض اليوم والقادمة والمتأخرة والمنجزة، والتقاطًا سريعًا يعرض تفسيرًا محدودًا للتاريخ والوقت قبل الحفظ، وعبء اليوم، وترشيحًا محليًا قابلًا للتفسير، والتكرار اليومي/الأسبوعي/الشهري، والتأجيل مع التراجع، ومؤقت تركيز، والنسخ الاحتياطي والاستيراد والدمج.

## النشر عبر GitHub Pages

ارفع **كل محتويات هذا المجلد** إلى جذر مستودع GitHub مع الحفاظ على ترتيب الملفات والمجلدات، ثم افتح **Settings → Pages**، واختر **Deploy from a branch** والفرع `main` والمجلد `/ (root)`، ثم اضغط **Save**. يجب رفع `index.html` و`manifest.webmanifest` و`service-worker.js` ومجلد `icons/` معًا.

بعد النشر على رابط HTTPS، افتحه في هاتفك. على Android استخدم خيار التثبيت أو «إضافة إلى الشاشة الرئيسية» من Chrome. على iPhone أو iPad افتحه في Safari ثم **مشاركة → إضافة إلى الشاشة الرئيسية**.

## البيانات والتوافق

تظل المهام والتركيز في مفتاح التخزين السابق `waqti-smart-v1`، ويقرأ الإصدار الثالث بيانات التطبيق القديمة عند استخدام **النطاق والرابط نفسيهما**. الأفكار والتفضيلات محفوظة في مفتاح منفصل `waqti-smart-v3-extras` حتى لا تمسحها نسخ التطبيق الأقدم عند تعديل مهمة. إذا انتقلت إلى نطاق أو منفذ أو بروتوكول مختلف، صدّر نسخة احتياطية أولًا؛ بيانات `localStorage` لا تنتقل تلقائيًا بين الأصول.

التصدير يضم المهام والأفكار واسم المستخدم واختيار المظهر. الاستيراد يدمج المهام والأفكار دون حذف الموجود، ولا يغيّر تفضيلات الجهاز الحالي. البيانات محلية وغير مشفّرة وغير متزامنة؛ تجنب إدخال كلمات المرور أو المعلومات الحساسة، واستورد الملفات الموثوقة فقط.

محلل الالتقاط السريع محدود بالقواعد المعروضة في التطبيق، والتقويم لا يتصل بـ Google أو Outlook. لا توجد مزامنة أو حسابات أو تعاون، ولا إشعارات خلفية مضمونة. التكرار ينشئ الموعد التالي عند إنجاز المهمة أثناء استخدام التطبيق، والمؤقت يتوقف عند إغلاق الصفحة.
