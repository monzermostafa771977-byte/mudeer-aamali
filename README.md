# وقتي بذكاء — الإصدار الثاني

تطبيق عربي لإدارة الوقت والمهام، قابل للتثبيت على الهاتف كـ PWA، ويعمل دون مكتبات أو خادم. بيانات المهام تبقى محليًا في المتصفح.

## ما الجديد؟

يجمع الإصدار الثاني المهام غير المؤرخة في «الوارد»، ويعرض المهام حسب اليوم والقادمة خلال سبعة أيام والمتأخرة والمنجزة. يتيح الالتقاط السريع تفسير كلمات عربية محدودة للتاريخ والوقت، ويعرض معاينة قبل الحفظ. يستطيع المستخدم مراجعة مهام اليوم وتأجيل أي مهمة إلى الغد مع تراجع، واختيار مهمة مناسبة الآن حسب قواعد واضحة للأولوية والتأخر والمدة. تظهر أيضًا تقديرات عبء اليوم، وتكرار يومي أو أسبوعي أو شهري يُنشئ الموعد التالي عند إكمال المهمة، ومؤقت تركيز قابل لتغيير المدة. أضيف التصدير والاستيراد والدمج المحلي لملف JSON.

## الرفع إلى GitHub Pages

ارفع **كل محتويات هذا المجلد** إلى جذر مستودع GitHub مع الحفاظ على المجلدات. يجب أن تبقى ملفات `index.html` و`manifest.webmanifest` و`service-worker.js` ومجلد `icons/` معًا. ثم افتح **Settings → Pages**، واختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم **Save**.

بعد نشر رابط HTTPS، افتحه على الهاتف. على Android استخدم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» من Chrome. على iPhone افتحه في Safari، واضغط «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».

## البيانات والحدود

يستعمل التطبيق مفتاح التخزين نفسه الذي استعمله الإصدار الأول (`waqti-smart-v1`) كي يقرأ المهام القديمة عند تحديث الملفات على **الرابط والأصل نفسيهما**. إذا تغيّر النطاق أو المنفذ أو البروتوكول، فلن ينقل المتصفح بيانات `localStorage` تلقائيًا؛ استخدم تصدير النسخة الاحتياطية قبل الانتقال.

ملف النسخة الاحتياطية JSON يدمج المهام عند استيراده ولا يحذف المهام الموجودة. احتفظ بنسخة خارج الجهاز؛ البيانات المحلية غير مشفّرة ولا تتزامن بين الأجهزة. لا تستورد ملفات من مصدر غير موثوق.

محلل الالتقاط السريع محدود بالكلمات والقواعد الموضحة داخل الصفحة؛ راجع المعاينة دائمًا ولا يعتبر ذكاءً اصطناعيًا أو فهمًا شاملًا للغة العربية. الاقتراحات محلية وحتمية، ولا تعيد جدولة المهام تلقائيًا. التكرار ينشئ المهمة التالية عند إكمال المهمة، وليس أثناء إغلاق التطبيق. مؤقت التركيز يتوقف عند إغلاق الصفحة. المزامنة السحابية وربط التقويم الخارجي والإشعارات المضمونة في الخلفية غير متاحة في هذه النسخة.
