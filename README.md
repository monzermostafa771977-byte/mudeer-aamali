# وقتي بذكاء — الإصدار الثالث

مدير أعمال شخصي عربي يعمل محليًا في المتصفح ويمكن نشره مجانًا على GitHub Pages كـ PWA. لا يحتاج إلى مكتبات أو خادم.

## ما الذي أضيف بالاستفادة من النموذج المرفق؟

- تقويم شهري محلي يعرض عدد المهام في كل يوم؛ الضغط على يوم يفتح مهامه في مساحة العمل.
- دفتر أفكار مستقل عن قائمة المهام، مع إمكانية تحويل الفكرة إلى مهمة في الوارد أو حذفها.
- حفظ اسم اختياري يظهر في التحية، وتبديل بين المظهر الفاتح والداكن
 الميزات الأساسية المتاحة

يشمل الإصدار أيضًا الوارد للمهام غير المؤرخة، وعروض اليوم والقادمة والمتأخرة والمنجزة، والتقاطًا سريعًا يعرض تفسيرًا محدودًا للتاريخ والوقت قبل الحفظ، وعبء اليوم، وترشيحًا محليًا قابلًا للتفسير، والتكرار اليومي/الأسبوعي/الشهري، والتأجيل مع التراجع، ومؤقت تركيز، والنسخ الاحتياطي والاستيراد والدمج.
